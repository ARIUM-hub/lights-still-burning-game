# 《灯火未熄》设计系统

> 本文件以已确认的产品设计为最高依据；UI Pro Max 的自动推荐仅用于补充交互与无障碍规则。

**产品：** 手机优先的沉浸式视觉小说
**风格：** 电影感都市雨夜、克制现实主义、文学叙事
**禁止：** 鲜艳游戏化配色、霓虹赛博朋克、卡通图标、Emoji 结构图标

## 颜色

| 语义 | 值 | 用途 |
|---|---|---|
| `--color-bg` | `#070D17` | 页面与场景降级背景 |
| `--color-surface` | `rgba(8, 14, 24, 0.88)` | 对白与浮层 |
| `--color-surface-solid` | `#111B2A` | 不透明面板 |
| `--color-text` | `#F1F5F9` | 主文字 |
| `--color-muted` | `#A9B5C6` | 次要信息，仍需满足对比度 |
| `--color-accent` | `#D8A15D` | 琥珀灯光、焦点与主操作 |
| `--color-accent-strong` | `#F0B96F` | 悬停与高亮 |
| `--color-border` | `rgba(216, 161, 93, 0.42)` | 对白框与选择边界 |
| `--color-danger` | `#F87171` | 破坏性操作与错误 |
| `--color-focus` | `#F8CF91` | 键盘焦点环 |

不提供明亮主题；本作品的暗色是叙事表达，不是可切换皮肤。所有正文对背景对比度至少 4.5:1。

## 字体

- 旁白、角色对白、结局标题：`"Noto Serif SC", "Songti SC", STSong, serif`。
- 按钮、章节、设置：`Inter, "Microsoft YaHei", system-ui, sans-serif`。
- 不依赖在线字体；使用系统回退保证断网可玩。
- 移动端正文至少 16px，行高 1.7–1.85；桌面正文最大行宽 42rem。

## 间距与形状

- 使用 4/8px 节奏：4、8、12、16、24、32、48、64。
- 选择按钮最小高度 52px，所有触控目标至少 44×44px，相邻目标至少 8px。
- 圆角克制：小控件 4px、浮层 8px；不使用夸张胶囊和卡通圆角。
- 阴影只用于分离对白层与场景：`0 16px 48px rgba(0,0,0,.36)`。

## 核心布局

- 场景舞台使用 `min-height: 100dvh`，移动端优先，尊重安全区。
- 画面占主导，对白固定在视觉下半区；选择出现时保持原场景并压暗背景。
- 375px、768px、1024px、1440px 检查；不得横向滚动。
- 桌面端限制舞台最大宽度与文字行长，不把移动端元素无限拉伸。

## 交互

- 点击完整对白后才显示选择；选择只能通过点击/键盘触发，不设置倒计时。
- 第一次推进补全逐字文本，第二次才进入下一行，防止误跳。
- 按钮按下反馈 80–150ms；常规淡入与状态变化 160–260ms。
- 不依赖 hover；hover 只是桌面端补充。所有可点击元素有 `cursor: pointer` 和可见 `:focus-visible`。
- 结构图标使用同一套 SVG 线性图标，不使用 Emoji。

## 动效与无障碍

- 动效只使用 opacity/transform，避免布局抖动。
- 系统或游戏设置要求减少动态时，关闭逐字、雨幕位移与大幅转场。
- 支持 Enter/Space 推进、数字键选择、Escape 关闭浮层。
- 选择区使用 `fieldset`/`legend`；错误用 `role="status"` 或 `aria-live="polite"`，不抢焦点。
- 场景图为氛围装饰时对读屏隐藏；剧情信息必须出现在正文中。

## 降级与性能

- 场景图加载失败显示同色系 CSS 渐变，不显示破图。
- 图片预留比例，后续使用本地 WebP；非当前场景延迟加载。
- 声音、图片、存档失败均不能阻断阅读和选择。
- 不引入在线字体、第三方脚本或运行时网络依赖。

## 交付检查

- [ ] 375px 下按钮、对白与安全区不冲突
- [ ] 键盘可完成推进与选择，焦点清晰
- [ ] 触控目标 ≥44px，间距 ≥8px
- [ ] 正文对比度 ≥4.5:1
- [ ] `prefers-reduced-motion` 和游戏内减少动态均有效
- [ ] 没有 Emoji 结构图标、任意超大 z-index 或布局位移 hover
- [ ] 场景资源失败时仍可完整游玩
