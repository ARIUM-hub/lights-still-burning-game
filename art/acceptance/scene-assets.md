# 场景插画验收记录

## 来源与发布边界

- 七张场景图由当前账号在即梦图片 4.0 中逐张生成，源图为 2560×1440 PNG。
- 用户已明确授权启用并保存账号级“去除水印”开关；左上角生成水印已关闭。
- 即梦仍强制显示右下角“即梦AI”品牌标识。本项目保留该标识，不裁切、不涂抹、不做规避性修图。
- GitHub 仓库已设置为私有。`art/source/` 源图只保存在私有仓库中；网页构建仅发布 `public/images/scenes/` 中的优化 WebP。
- 图片的使用与公开展示仍受生成账号和即梦平台条款约束；本仓库不额外声明对平台标识、生成式文字或第三方元素拥有商标权。

## 逐图人工验收

| 场景 | 已确认内容 | 已知限制 |
| --- | --- | --- |
| `cafe` | 雨夜咖啡店、高架、店员背影和对白留白符合叙事 | 菜单、杯身和窗外存在生成式标识或伪文字 |
| `apartment` | 旧公寓、两名租客和压抑暖光可用 | 窗口比提示词预期更开放 |
| `store` | 热牛奶、硬币、两人互动和便利店构图完整 | 泡面杯及店内外招牌存在生成式伪文字 |
| `riverside` | 江边人物、远景灯火和疏离氛围符合叙事 | 远处建筑有生成式招牌细节 |
| `warehouse` | 店员背影、手机、行李袋和仓库压迫感可用 | 时钟没有严格表现为 8:50，纸箱有生成式文字 |
| `street` | 白玫瑰、雨夜街口和医院外告别氛围可用 | 存在医院文字、红十字式符号、女摊主侧脸及轻微黑边 |
| `station` | 南站冷清空间和离别氛围可用 | 存在第二个人影、车票/站内生成式文字 |

所有 WebP 已验证为 1920×1080、可解码且单张小于 600KB。桌面 1440×900 首屏与手机 375×812 全剧情路线均完成实际页面检查，七张图片加载正常且没有横向溢出。
