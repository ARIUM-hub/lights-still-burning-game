# 《灯火未熄》场景插画设计规格

## 1. 目标与范围

为现有手机优先视觉小说补齐七张本地场景插画，使全部剧情节点在联网和断网状态下都能显示统一画风的专属背景，并通过 GitHub Pages 向手机与电脑浏览器交付。

本次只处理 `SceneId` 已定义的七个场景：

| 场景 ID | 剧情用途 | 输出文件 |
| --- | --- | --- |
| `cafe` | 咖啡店夜班、客诉与独自清洁 | `public/images/scenes/cafe.webp` |
| `apartment` | 旧公寓楼道、出租屋与大壮对话 | `public/images/scenes/apartment.webp` |
| `store` | 便利店热牛奶与硬币相遇 | `public/images/scenes/store.webp` |
| `riverside` | 江边照片与自卑猜测 | `public/images/scenes/riverside.webp` |
| `warehouse` | 商场仓库、手机来电与九点倒计时 | `public/images/scenes/warehouse.webp` |
| `street` | 雨夜花摊、医院外与白玫瑰 | `public/images/scenes/street.webp` |
| `station` | 南站赶车、迟到与列车驶离 | `public/images/scenes/station.webp` |

标题页不新增独立图片，也不扩展剧情节点或结局。

## 2. 生成策略与供应商保护

- 复用用户已确认画风的 `store` 成图，不再次消耗生成积分。
- 其余六张使用即梦图片 4.0、16:9、高清 2K 逐张生成。
- 只使用一个已登录会话，严格串行；上一张生成完成并检查后，才提交下一张。
- 正常情况下共六次新请求、预计六积分；不并发、不批量重试、不切换供应商规避冷却。
- 单张失败时只做一次状态确认。遇到限流、账号验证或连续失败立即停止，由用户决定是否延迟重试。
- 不擅自修改账号级水印或法律声明设置；若原图下载被此类设置阻断，暂停并单独向用户确认。

实际执行时已按此规则暂停，并取得用户对“去除水印”账号开关的明确授权后保存设置。该开关移除了左上角生成水印，但平台仍强制保留右下角“即梦AI”品牌标识；项目不裁切、涂抹或以其他方式规避该标识。

## 3. 统一视觉母提示词

每张图片都使用以下共同约束：

> 只生成一张图片，不生成视频或文案。16:9 横向视觉小说场景插画，达到精细商业叙事插画成片质量。电影感都市现实主义二维数字绘景，现代中国大城市 A 市的深夜雨季。构图具有明确的前景、中景和背景层次，叙事物件清晰但不刻意摆拍；建筑透视准确，人物比例与手部结构自然。深蓝黑与雾灰为主色，只有克制的琥珀暖光；光源方向统一，明暗过渡细腻，暗部保留纹理而不死黑。潮湿空气、细密雨丝、湿润地面倒影、玻璃反射、布料褶皱、墙面与金属材质都具有丰富但克制的细节。远处散景和轻微电影颗粒，35mm 电影镜头，宽容度高、焦点层次自然，安静、孤独、克制而忧伤，不是赛博朋克。人物使用侧后方中远景、侧影或背影，不展示清晰正脸，不直视镜头。主体位于画面中上部，底部约 35% 保留深色低细节区域供游戏对白框覆盖。不要夸张表情，不要僵硬摆拍，不要塑料质感，不要过度锐化，不要高饱和霓虹，不要日漫大眼睛，不要欧美城市，不要文字，不要乱码招牌，不要品牌标志，不要水印，不要边框，不要对白框。所有场景保持一致的镜头语言、人物比例、细节密度、色彩分级和雨夜质感。

### 精美度标准

- **构图层次**：每张图都有前景遮挡或反射、中景叙事主体和背景环境信息，避免所有物件平均分布。
- **光影品质**：冷色环境光与单一琥珀暖光形成克制对比，光源、阴影和反射方向一致，不出现无来源轮廓光。
- **材质细节**：雨水、玻璃、湿布料、旧墙、金属和纸张可被区分；细节服务情绪，不堆砌装饰。
- **人物可信度**：人物姿势松弛自然，手指、四肢与座椅接触合理；正脸继续隐藏，避免因追求精致而出现蜡像感。
- **电影感后期**：保留暗部细节、压制高光、使用轻微颗粒和自然景深；不使用廉价蓝橙滤镜或过度锐化。
- **叙事焦点**：每张图只突出一至两个关键物件，例如硬币、白玫瑰、手机、时钟或车票残角。

## 4. 各场景追加提示词

### `cafe`

连锁咖啡店打烊后的空旷内景，玻璃窗外能看见雨夜高架和流动尾灯。操作台冷光、咖啡机白汽、几张空桌和一只翻倒但没有标志的纸杯。一名穿深色旧制服的年轻店员独自弯腰清洁，肩膀略微下沉，只出现侧后方身影。画面重点是疲惫、过度懂事和城市不会为任何人停下。

### `apartment`

狭窄老旧公寓的楼道尽头，一扇小窗外只有邻楼空调外机，暖黄灯泡与高架车灯从窗缝掠过。两名从小地方来到城市的年轻男人并肩坐在窗边台阶上，各拿一罐最便宜的无标识啤酒；其中一人低头捏皱铝罐。墙面潮湿斑驳，空间逼仄但关系安静，不展示清晰正脸。

### `store`

复用已确认成图：深夜便利店靠窗吧台，一杯冒着热气的牛奶和一桶泡面，穿浅米色毛衣的年轻女人把硬币放回穿深色旧外套的年轻男人掌心；窗外大雨、城市散景与积水倒影。最终原图需尽量避免杯身和招牌上的伪文字；如无法无损处理，保留画面并在验收记录中明确说明。

### `riverside`

雨后灰蓝色江面与被风吹斜的芦苇，远处是 A 市克制的灯火和桥梁轮廓。画面像一张被年轻摄影者拍下的照片：一名穿浅色长外套的年轻女人站在江边栏杆附近回头，但距离很远，只保留轮廓和被风带起的衣摆；另一个拍摄者不入镜。整体美丽但疏离，让观看者产生自己不属于画面的感觉。

### `warehouse`

商场咖啡店后方的狭窄仓库，堆叠纸箱、无标识纸杯箱和金属货架形成压迫透视。墙上指针时钟接近九点，纸箱旁一部手机亮起但屏幕没有文字，一只半藏在更衣柜旁的旧行李袋。年轻店员站在仓库门与货架之间，手搭在行李袋提手上，像正在决定离开还是继续盘点。

### `street`

医院急诊楼外的雨夜街口与地铁出口，小型花摊的透明塑料雨棚积着水，桶里有一枝略微卷边的白玫瑰；远处救护车红光掠过湿墙和路面，但不出现医院或药店文字。一名栗色头发的年轻女摊主把白玫瑰递向穿深色旧外套的年轻男人，两人保持中远景侧影。场景同时能承接花摊劝告和医院外告别，悲伤但不煽情。

### `station`

A 市南站末班车离开后的空站台和明亮却冷清的候车空间，远处只有列车尾灯消失在雨幕中。地面有雨水脚印和一张被踩脏的车票残角，不出现可读车次、站名或广告。一名裤脚与鞋都湿透的年轻男人停在站台中央喘息，身体很小，大片空旷空间强调迟到和无法追回。

## 5. 资产管线

- 从即梦下载的 2K 原图保存在 `art/source/<scene>.<原格式>`，作为可追溯源文件。
- 新增 `scripts/optimize-images.mjs`，使用项目已安装的 `sharp`：
  - 自动处理源文件实际格式；
  - 居中裁切或缩放到 1920×1080；
  - 输出 WebP，质量 82、`effort: 6`；
  - 已存在文件采用明确场景名覆盖，因为这些文件是本功能的确定性构建产物。
- 产物放入 `public/images/scenes/`，文件名严格等于七个 `SceneId`。
- 每张目标大小不超过 600KB；如果超过，只降低 WebP 质量或清理元数据，不改变构图。
- 当前 `StoryStage` 已按 `/images/scenes/${scene}.webp` 加载，因此接入以补齐资产为主，不改变剧情组件接口。

## 6. 验收与异常处理

逐张检查：

1. 尺寸为 1920×1080，比例 16:9，WebP 可正常解码。
2. 画风、色彩和镜头语言与已确认的便利店样图一致。
3. 主体不被游戏底部对白框遮挡，手机窄屏裁切后仍保留关键叙事物件。
4. 在 100% 放大检查中，雨水、玻璃、布料和环境表面细节清晰自然，暗部不糊成色块，高光不过曝。
5. 不出现清晰正脸、畸形肢体、明显乱码、品牌标志、生成水印、塑料质感或突兀高亮区域。
6. 图片缺失或加载失败时，现有 CSS 渐变降级仍可完整游玩。

不合格图片只针对一个明确缺陷调整提示词并串行重生成一次；若仍不合格或出现限流，停止并报告实际缺口，不连续请求。

本轮生成已执行单图最多一次重试并停止继续请求。最终资产仍有平台强制品牌标识和少量生成式伪文字，具体逐图记录见 `art/acceptance/scene-assets.md`；这些属于用户已知的首版限制，不代表已经满足上方理想化的“无文字、无水印”目标。

## 7. 测试、接入与部署

- 为优化脚本和七个固定资产补充确定性测试，验证场景清单、输出尺寸与文件存在性。
- 运行 `npm test`、`npm run build` 和 `npm run build:pages`。
- 使用手机视口检查标题页、七个场景、对白框和选择面板；确认图片加载成功且不会造成横向滚动。
- 将源图、WebP、优化脚本、测试和必要的文档提交到当前分支。
- 推送 `codex/lights-still-burning-game`，等待 GitHub Pages 工作流完成后验证公开页面，再交付手机可访问链接。

## 8. 完成标准

- 七个 `SceneId` 均有可用本地 WebP，断网构建不依赖远程图片。
- 七张图视觉统一并通过人工画面检查。
- 自动化测试与两个生产构建命令全部通过。
- GitHub Pages 部署成功，交付链接可在手机浏览器打开并正常游玩。
